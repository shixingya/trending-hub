📦 响应格式

API 返回一个数组，每个元素代表一个平台的数据：

[
  {
    "source": "知乎热榜",
    "key": "zhihu",
    "icon": "知",
    "color": "#0066ff",
    "items": [
      {
        "title": "话题标题",
        "url": "https://www.zhihu.com/question/123",
        "hot": 14420000,
        "description": "话题描述（可选）"
      }
    ],
    "fetchedAt": "2026-10-05T12:00:00.000Z"
  }
]
字段说明：
source string - 平台名称
key string - 平台唯一标识
icon string - 平台图标（emoji 或文字）
color string - 平台主题色（HEX）
items array - 话题列表
items[].title string - 话题标题
items[].url string - 话题链接
items[].hot number - 热度值（可选）
items[].description string - 话题描述（可选）
fetchedAt string - 数据抓取时间（ISO 8601）

💡 使用示例

示例 1：获取今日 TOP 10 热点

fetch('https://shixingya.github.io/trending-hub/data/trending.json')
  .then(res => res.json())
  .then(data => {
    // 合并所有平台的话题
    const allItems = data.flatMap(source => 
      source.items.map(item => ({
        ...item,
        source: source.source,
        sourceIcon: source.icon
      }))
    );
    
    // 按热度排序，取 TOP 10
    const top10 = allItems
      .filter(item => item.hot)
      .sort((a, b) => b.hot - a.hot)
      .slice(0, 10);
    
    console.log(top10);
  });

示例 2：在网页中显示 GitHub Trending

<ul id="github-trending"></ul>

<script>
fetch('https://shixingya.github.io/trending-hub/data/trending.json')
  .then(res => res.json())
  .then(data => {
    const github = data.find(d => d.key === 'github-trending');
    const list = document.getElementById('github-trending');
    
    github.items.slice(0, 10).forEach(item => {
      const li = document.createElement('li');
      li.innerHTML = `<a href="${item.url}" target="_blank">${item.title}</a>`;
      list.appendChild(li);
    });
  });
</script>
